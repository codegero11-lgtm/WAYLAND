# Projeto Aracne

Estrutura inicial do repositório para o robô octápode Aracne.

## Organização

- `docs/` — documentação de arquitetura, roteiro e contratos.
- `src/` — pacotes ROS2 e código fonte.
- `src/aracne_description/` — URDF/Xacro e modelos da perna.
- `src/aracne_bringup/` — launch files e configurações.
- `src/aracne_leg_kinematics/` — nó de cinemática inversa.
- `src/aracne_teleop/` — teleoperação de teste.
